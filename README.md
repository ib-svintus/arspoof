# ARSpoof — Скрипт для ARP-спуфинга

Простой инструмент на Python с использованием библиотеки **Scapy**, предназначенный для демонстрации уязвимостей протокола ARP (ARP-spoofing / Man-in-the-Middle) и сканирования устройств в локальной сети.

Этот проект создан исключительно в образовательных целях и для тестирования на проникновение в рамках авторизованных аудитов безопасности. Использование утилиты в коммерческих или вредоносных целях без согласия владельца сети строго запрещено.

## Функционал
* **Сканирование сети:** Автоматически определяет активные устройства в подсети на выбранном сетевом интерфейсе.
* **Определение OS:** Пытается определить операционную систему целевого устройства по значению TTL (Time to Live) из ICMP-ответов (Linux/Android, Windows).
* **ARP-спуфинг:** Проводит атаку «человек посередине» (MitM), отправляя ложные ARP-ответы жертве и роутеру.
* **Автоматическое восстановление:** При прерывании работы скрипта (комбинация `Ctrl + C`) сетевые таблицы устройств корректно восстанавливаются.

## Требования к системе
* **ОС:** Windows, Linux или macOS.
* **Права:** Запуск с правами администратора (root), так как Scapy работает с сетевыми пакетами на низком уровне.
* **Установленный Python:** Версия 3.8 или выше.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ib-svintus/arspoof
   cd arspoof
   ```

2. **Создайте и активируйте виртуальное окружение (рекомендуется):**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для Linux/macOS:
   source venv/bin/activate
   ```

3. **Установите необходимые зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Включите форвадинг пакетов**
   * Set-NetIPInterface -Forwarding Enabled В Powershell от Администратора на Windows
   * echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward в терминале на линукс

5. **Запустите скрипт:**
   * В **Windows** откройте командную строку/PowerShell от имени Администратора:
     ```bash
     python main.py
     ```
   * В **Linux/macOS** используйте `sudo`:
     ```bash
     sudo python3 main.py
     ```

## Использование
1. При запуске скрипт выведет список доступных сетевых интерфейсов. Введите номер нужного интерфейса.
2. Программа проведет сканирование вашей сети и отобразит список IP и MAC-адресов.
3. Введите запрашиваемые данные для атаки:
   * IP и MAC-адрес жертвы (`Victim`).
   * IP и MAC-адрес роутера (`Router`).
4. Для остановки атаки и восстановления сети нажмите **`Ctrl + C`**.
